IMPORTANT BEFORE PUBLIC LAUNCH
This is a front-end prototype, not a production e-commerce system. The demo admin login is visible in the page source and must not be used for a live store. Product data is stored only in the current browser. A secure backend/database, server-side admin authentication, order management, HTTPS, and a verified payment-provider integration are still required. No card or Mobile Money payment is processed yet. Payment integration needs the merchant account/API credentials from the chosen provider.
